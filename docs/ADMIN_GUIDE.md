# Admin guide

1. Seed the first Owner with `scripts/seed-owner.mjs`.
2. Sign in and add a Resend domain under Administration → Sending Domains,
   paste its domain-restricted API key, verify it, and run a connectivity test.
3. Create a mailing list and add contacts, or create segments.
4. Create a campaign, choose a verified domain and sender identity, select the
   audience, and send or schedule.
5. Monitor per-domain and per-campaign reports, and use Settings for test mode,
   the kill switch, and the daily limit.
